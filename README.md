# 直齿圆柱齿轮传动链实验室（Spur Gear Train Lab）

纯浏览器、无后台的教学工具：用 Vue 3 + TypeScript 提供参数输入，Three.js 显示三维齿形与运动，
Clipper2 的 WASM 版本做实体轮廓布尔求交（局部干涉），IndexedDB 保存案例。

支持 **一对外啮合双轮** 与 **三轮惰轮链（输入轮–惰轮–输出轮，两段独立外啮合）** 两种可配置形态，
用于让学生看清 **齿数 z、模数 m、压力角 α** 如何影响尺寸、齿形与啮合，以及
**惰轮为什么改变传动方向、为什么不能只看一对齿轮、也不能把总速比直接套到末轮**。

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建（dist/，可直接静态托管）
npm test           # 齿形 / 双轮啮合 / 三轮链验收 / 案例往返 的数值核对
```

## 模型适用范围（重要）

- **仅外啮合**、**无变位**、**理想刚性** 的标准渐开线直齿轮（双轮或三轮链，共线布置）；
- 刀具系数：齿顶高系数 ha*=1、顶隙系数 c*=0.25、齿根圆角 ρf*≈0.38（教学近似）；
- 每段默认标准中心距 a₀=m(z左+z右)/2 安装（理论无侧隙）。允许改任一段中心距以**观察**
  侧隙/顶隙变化，此时给出实际啮合角与侧隙，但属于有侧隙安装，不再是无侧隙正确啮合；
- 不考虑弹性、摩擦、热膨胀、制造误差、动载荷；齿廓为端截面 2D 挤出；
  不含斜齿轮、内齿轮、变位齿轮；
- 当 z < z_min = 2/sin²α（α=20° 时 ≈ 17.10）会标红提示**根切风险**；齿廓仍闭合可用，
  但根部为简化几何，仅示意，不代表真实可制造齿形。
- 说明：标准外啮合下两轮齿顶圆恒相互越过中心线（ra1+ra2 > a0），齿顶落入对方齿槽空间，
  实体并不重叠；是否真正碰撞以顶隙符号与 Clipper 实体求交为准（本工具提供逐段求交）。

## 渐开线公式与范围

基圆半径 r_b = r·cosα，分度圆 r=mz/2。展开参数 t（滚动角）下：

```
x(t) = r_b (sin t − t cos t)
y(t) = r_b (cos t + t sin t)
向径 R(t) = r_b√(1+t²)，压力角 α_t 满足 t = tan α_t
展角（渐开线函数）inv(α) = tan α − α
```

- t∈[0, t_a]，t_a=√((r_a/r_b)²−1)；**基圆以内无渐开线**（用径向线 + 刀具圆角过渡）。
- 齿面构造旋转角 β = π/(2z) + inv(α)；齿顶单侧半角 = π/(2z)+invα−invα_a（即教材 s_a 公式）。

## 为什么"惰轮改变方向"，且不能把总速比直接套到末轮

速比 ω2/ω1 = −z1/z2 只是**必要条件**。每一段装配都同时保证：

1. 两轮模数、压力角相等 → 基节 p_b=πm·cosα 相等（界面逐段检查；任一段不匹配即**拒绝形成链条**，
   不会给出半成品传动链）；
2. **相位正确**：节点 P 处两轮接触齿面共法线（沿啮合线）；
3. 沿啮合线滚动时始终是**同一条渐开线**接触：

```
t左 = tanα′ + s/rb左,  t右 = tanα′ − s/rb右
dφ左/ds = +1/rb左,  dφ右/ds = −1/rb右
⇒ rb左·Δφ左 = −rb右·Δφ右   （一段外啮合反向一次）
```

三轮链姿态沿 **φ1 →（段1 反解 s1）→ φ2 →（段2 反解 s2）→ φ3** 逐段严格传播（见 `src/geometry/train.ts`）：

- 每段都是一次外啮合、方向反转一次；两段后**首末轮同向**；
- 惰轮齿数在总速比幅值中**约掉**：ω3/ω1 = (−1)²·z1/z3 = **+z1/z3**；
- 符号 (−1)^n 来自"外啮合次数 n=2"，而不是某一对轮的齿数；若误以为首末轮"是一对外啮合"
  而取负号，末轮摆位立刻出错（`check-train.ts` 用 Clipper 证明该错误摆位产生伪干涉）；
- 惰轮的中间相位由**两段啮合同时**约束，跳过惰轮无法构造自洽的全链姿态；
- 暂停时拖动**任一段**接触点 s，其余段和所有轮的相位由真实啮合双向反推（下游正向、上游反向），
  末轮绝不是用总速比直接旋转。

`npm test` 的 `check-mesh.ts` / `check-train.ts` 用解析渐开线逐点核对：接触点同时落在两轮齿面上、
各段转角比恰为 −z左/z右、转向相反、rb左·Δφ左=−rb右·Δφ右，并积分得到首末轮同向的总速比。

## 功能

- **双轮 / 三轮惰轮链**可切换；每轮独立齿数，模数/压力角逐段校验，不匹配明确拒绝；
- **暂停**：停在任意位置；可在"检查第 1 段 / 第 2 段"间切换，拖该段"接触点 s"滑块沿理论
  啮合线检查接触位置，全三轮转到严格对应相位（上下游联动）；
- **局部干涉**：暂停后对选中段（或两段全部）用 Clipper2 WASM 求当前帧两轮实体轮廓交集，
  红色高亮重叠区并给面积；
- 参考圆（节圆/基圆/齿顶/齿根）、理论啮合线（灰）与实际啮合段（绿）、节点、接触点可切换；
- **单位切换** mm/cm/m/in 只改显示换算，内部始终存 mm，实际尺寸不变；
- 逐段中心距、啮合角 α′、节圆、侧隙、顶隙、重合度 ε_α、基节一致性、根切/变尖检查实时显示；
  总速比、外啮合次数、首末轮方向由模型给出；
- **案例**：IndexedDB 本地保存/载入；自描述 JSON（schema v2）可勾选附带**三个轮廓**与
  **两段干涉检查结果 + 当时姿态角**；导出文件可重新导入（随载轮廓可直接用于 Clipper 求交，
  刷新/导入后惰轮参数、两段检查结果、轮廓与相位均不丢失）；**旧 v1 双轮案例自动迁移**，
  按原行为运行，并可一键另存为三轮惰轮链。

