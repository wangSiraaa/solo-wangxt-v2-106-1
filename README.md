# 直齿圆柱齿轮传动链实验室（Spur Gear Train Lab）

纯浏览器、无后台的教学工具：用 Vue 3 + TypeScript 提供参数输入，Three.js 显示三维齿形与运动，
Clipper2 的 WASM 版本做实体轮廓布尔求交（局部干涉），IndexedDB 保存案例。

用于让学生看清 **齿数 z、模数 m、压力角 α** 如何影响齿轮尺寸、齿形与啮合，并通过
**含中间惰轮的三轮传动链**理解：**惰轮为何改变传动方向——必须看两段真实啮合，不能只看一对齿轮
或把总速比直接套到末轮。**

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建（dist/，可直接静态托管）
npm test           # 解析尺寸 / 齿形闭合 / 啮合相位 / 导入导出往返 的数值核对
```

## 模型适用范围（重要）

- **仅外啮合**、**无变位**、**理想刚性** 的标准渐开线直齿轮；支持两种轮系：
  一对齿轮（`pair`，旧实验）与 **含中间惰轮的三轮传动链 O1–O2–O3**（`chain`）；
- 三个轮的模数、压力角**各自独立输入**；只有同一啮合副两轮的 m、α 分别相等（基节相等）
  才允许成链——任一不匹配时**拒绝形成半成品传动链**（不产生啮合、不给相位）；
- 刀具系数：齿顶高系数 ha*=1、顶隙系数 c*=0.25、齿根圆角 ρf*≈0.38（教学近似）；
- 每段独立按标准中心距 a₀=m(z左+z右)/2 安装（理论无侧隙）。允许改任一段中心距以**观察**
  侧隙/顶隙变化，此时该段给出实际啮合角与侧隙，但属于有侧隙安装；
- 不考虑弹性、摩擦、热膨胀、制造误差、动载荷；齿廓为端截面 2D 挤出；
  不含斜齿轮、内齿轮、变位齿轮；
- 当 z < z_min = 2/sin²α（α=20° 时 ≈ 17.10）会标红提示**根切风险**；齿廓仍闭合可用，
  但根部为简化几何，仅示意，不代表真实可制造齿形。

## 渐开线公式与范围

基圆半径 r_b = r·cosα，分度圆 r=mz/2。展开参数 t（滚动角）下：

```
x(t) = r_b (sin t − t cos t)
y(t) = r_b (cos t + t sin t)
向径 R(t) = r_b√(1+t²)，压力角 α_t 满足 t = tan α_t
展角（渐开线函数）inv(α) = tan α − α
```

- t∈[0, t_a]，t_a=√((r_a/r_b)²−1)；**基圆以内无渐开线**（用径向线 + 刀具圆角过渡）。
- 齿面构造旋转角 β = π/(2z) + inv(α)；齿顶单侧半角 = π/(2z)+invα−invα_a（即教材 s_a 公式）。

## 为什么不是"按转速比旋转就算正确啮合"

速比 ω₂/ω₁ = −z₁/z₂ 只是**必要条件**。本工具的装配同时保证：

1. 两轮模数、压力角相等 → 基节 p_b=πm·cosα 相等（界面有检查）；
2. **相位正确**：节点 P 处两轮接触齿面共法线（沿啮合线）。接触的是轮1 左齿面 / 轮2 右齿面；
3. 沿啮合线滚动时始终是**同一条渐开线**接触。由几何严格推导（见 `src/geometry/mesh.ts` 注释）：

```
t1 = tanα′ + s/r_b1,  t2 = tanα′ − s/r_b2
dφ1/ds = +1/r_b1,  dφ2/ds = −1/r_b2
⇒ r_b1·Δφ1 = −r_b2·Δφ2   （外啮合反向）
```

`npm test` 的 `check-mesh.ts` 用解析渐开线逐点核对：接触点同时落在两轮齿面上、转角比恰为
−z₁/z₂、转向相反、r_b1·Δφ1=−r_b2·Δφ2。

## 惰轮为什么改变方向：两段真实啮合同时决定（三轮链）

三轮链包含**两段独立的真实外啮合**，惰轮（轮2）在段 A 是从动轮、在段 B 同时是主动轮，
它只有**一个**本体转角，必须同时满足两段严格相位：

```
段 A(1–2)：rb1·Δφ1 = −rb2·Δφ2      ⇒ i_A = −z1/z2
段 B(2–3)：rb2·Δφ2 = −rb3·Δφ3      ⇒ i_B = −z2/z3
总速比     Δφ3/Δφ1 = i_A·i_B = (+) z1/z3   ← 两段相乘，不是直接套到末轮
首末轮转向：相同（两次外啮合，方向反转两次）；惰轮与首、末轮各自转向相反
```

实现上（`src/geometry/chain.ts`）绝不把总速比直接赋给末轮，而是严格级联：

```
φ1 →(反解 s1)→ φ2（惰轮唯一转角）→(反解 s2)→ φ3
```

- **中心距、啮合角、节圆、侧隙、顶隙、重合度、啮合线、接触点** 按段独立计算与显示，
  Three.js 中可用"检查副 A / 检查副 B"选择任一啮合副（未选段暗淡但仍可见，两段同时存在）；
- **任一暂停时刻的三轮姿态**都由 `poseFromMaster(φ1)` 经两段真实啮合同时求出；
- 暂停后可沿**任一段**啮合线拖动接触点：拖段 A 时 φ2、s2、φ3 随之严格级联；
  拖段 B 时由惰轮转角作为段 B 主动轮给出 φ3，并**反推**段 A（惰轮此时是从动轮）得到 φ1；
- 沿啮合线的理论参数 s 可超出当前齿对（延长渐开线）。显示/检查用 s 按**基节 p_b**
  周期折叠到实际啮合线段（`reduceToAction`）：s 相差整数个 p_b 时两轮各转整齿距角，
  姿态在齿轮旋转对称下物理等价，轮廓与 Clipper 求交结果不变。姿态本身始终由连续 s 求出，
  保证 r_b·Δφ 关系在任意时刻严格成立。

`check-chain.ts` 逐点核对：两段接触点都在真实渐开线齿面上、惰轮单一转角同时满足两段
rb·Δφ 关系、总速比为 +z1/z3、首末轮同向；模数/压力角不匹配时拒绝成链且不提供运动学；
正向/反向拖动后另一段与末轮相位仍严格一致。

## 功能

- **轮系模式**：一对齿轮（旧实验）/ 含惰轮三轮链，三个轮齿数/模数/压力角/齿宽独立配置；
  模数或压力角不匹配时整链被拒绝并逐段给出原因（不产生半成品啮合）；
- **暂停**：停在任意位置，选择检查副 A 或副 B，拖"接触点 s"滑块沿该段理论啮合线检查
  （另一段接触位置与末轮相位自动严格级联/反推，始终对应同一条渐开线）；
- **局部干涉**：暂停后用 Clipper2 WASM 对当前帧**任一段**两轮实体轮廓求交，
  红色高亮重叠区并给面积；两段结果各自独立保存；
- 参考圆（节圆/基圆/齿顶/齿根）、两段理论啮合线（灰）与实际啮合段（绿/暗）、
  节点、两段接触点可切换；
- **单位切换** mm/cm/m/in 只改显示换算，内部始终存 mm，实际尺寸不变；
- 每段中心距、啮合角 α′、节圆、侧隙、顶隙、重合度 ε_α、基节一致性、根切/变尖检查实时显示；
  总速比与首末轮转向由两段外啮合关系相乘给出；
- **案例**：IndexedDB 本地保存/载入；**schema v2 版本化**，自动迁移旧 v1 双轮案例
  （载入后按原双轮行为运行，可一键"扩为三轮链"后另存）；可导出自描述 JSON
  （含各轮局部轮廓、暂停姿态、两段干涉检查结果），导出文件可重新导入，
  随载轮廓可直接用于 Clipper 求交，姿态始终由保存的 φ1 重新严格级联（不重建为错误相位）。

## 代码结构

```
src/geometry/gear.ts    解析尺寸、渐开线齿廓、闭合外环、输入校验
src/geometry/mesh.ts    单副装配：啮合角/节圆/侧隙/顶隙/重合度、啮合线、严格啮合相位、
                        s 反解（主动/从动侧）、按基节折叠到实际啮合齿对
src/geometry/chain.ts   轮系（pair/chain）：分段装配与拒绝、严格相位级联/反推、
                        总速比与方向（两段相乘）、世界坐标接触点
src/geometry/clipper.ts Clipper2 WASM 封装（IntersectD / AreaPathsD）
src/viewer.ts           Three.js N 个齿形挤出、参考圆、各段啮合线/接触点（世界坐标）、
                        分段干涉高亮、运动
src/store.ts            IndexedDB 与版本化案例 JSON（v2，迁移 v1 双轮案例）
src/units.ts            显示单位换算（内部恒为 mm）
src/App.vue             模式/参数面板、分段检查结果、动画/暂停/拖动、案例管理
scripts/                数值核对（齿轮、单副啮合、三轮链、版本化往返）
```
